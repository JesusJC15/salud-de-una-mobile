# docs/agent-skills/github-actions

Skill para definir flujos de GitHub Actions orientados a mobile, artefactos y automatizaciones de CI.

## Que vas a encontrar aqui

- `SKILL.md` con el flujo principal
- `agents/` para configuracion de agentes relacionados
- `references/` con ejemplos y wiring detallado

## Cuando usar esta skill

- al crear workflows de build movil
- al documentar artefactos descargables
- al preparar CI para lint, build o distribucion interna

## Checklist para contributors

- Revisa primero `SKILL.md`.
- Si necesitas comandos o ejemplos, baja a `references/`.
- Mantiene consistencia con `.github/workflows/`.

## Do and don't

### Do

- Usa esta skill para pipelines reproducibles.

### Don't

- No inventes workflows sin revisar los patrones ya documentados.
