# docs/agent-skills

Esta carpeta concentra los playbooks locales que guian a contributors y asistentes al trabajar en este repositorio.

## Proposito

- servir como fuente de verdad para buenas practicas locales
- reducir decisiones improvisadas
- enlazar a referencias concretas por tema

## Que va aqui

- skills por dominio o flujo de trabajo
- instrucciones generales para asistentes
- referencias complementarias de cada skill

## Que no va aqui

- codigo de aplicacion
- decisiones temporales sin mantenimiento

## Reglas y convenciones

- Antes de cambios relevantes, revisa `AGENT_SKILLS.md`.
- Sigue `CODING_ASSISTANT_INSTRUCTIONS.md` para el flujo general.
- Cada skill debe tener un alcance claro.

## Checklist para contributors

- Si agregas una skill, documenta entrada, uso y referencias.
- Si cambias una practica oficial, actualiza la skill correspondiente.

## Do and don't

### Do

- Usa esta carpeta como sistema de conocimiento vivo del repo.

### Don't

- No conviertas las skills en documentos largos sin estructura.
