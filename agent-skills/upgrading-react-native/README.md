# docs/agent-skills/upgrading-react-native

Skill para planear y ejecutar upgrades de React Native y Expo con criterio y verificacion.

## Que vas a encontrar aqui

- `SKILL.md` con el proceso general
- `agents/` para apoyo automatizado
- `references/` con checklists y material de soporte

## Cuando usar esta skill

- al subir version de Expo SDK
- al subir version de React Native
- al revisar compatibilidad de dependencias y validacion post-upgrade

## Checklist para contributors

- Revisa esta skill antes de cualquier upgrade importante.
- No mezcles upgrades grandes con cambios funcionales si puedes evitarlos.
