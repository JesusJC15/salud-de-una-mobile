# Instrucciones para el asistente (Copilot/Codex)

Cuando el usuario pida ayuda, SIEMPRE:

1) Lee `AGENT_SKILLS.md` y elige la skill apropiada.
2) Abre el `SKILL.md` de esa skill y sigue el flujo que indica.
3) Si hace falta detalle, consulta `references/` dentro de la skill.
4) Si hay conflictos entre prácticas, prioriza:
   - seguridad y estabilidad del build
   - pasos reproducibles
   - cambios pequeños y revisables

Convención al responder:
- Incluye un plan paso a paso.
- Señala qué archivos se van a tocar (y por qué) antes de cambiarlos.
