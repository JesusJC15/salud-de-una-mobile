# assets

Esta carpeta guarda recursos estaticos consumidos por la aplicacion.

## Que va aqui

- iconos
- splash assets
- imagenes de soporte

## Reglas y convenciones

- Usa nombres descriptivos y estables.
- Prefiere formatos y tamanos optimizados.
- Separa recursos por tipo cuando la carpeta crezca.

## Que no va aqui

- contenido temporal
- binarios de build
- documentos de analisis

## Checklist para contributors

- Revisa si el asset se reutiliza o es exclusivo de una feature.
- Optimiza peso antes de subirlo.
- Documenta nuevos subdirectorios si aparecen.

## Do and don't

### Do

- Mantiene este arbol limpio y predecible.

### Don't

- No subas recursos sin uso claro.
