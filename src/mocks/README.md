# src/mocks

Mocks, fixtures y adaptadores de prueba para desarrollo y testing.

## Que va aqui

- payloads de ejemplo
- respuestas mockeadas de backend
- data builders sencillos

## Que no va aqui

- data real de usuarios
- archivos temporales sin uso recurrente

## Checklist para contributors

- Mantiene mocks alineados con contratos reales.
- Si cambia una respuesta backend, actualiza sus mocks.
