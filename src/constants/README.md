# src/constants

Constantes compartidas de aplicacion, incluyendo tema y tokens base.

## Que va aqui

- claves de query
- llaves estables de feature
- copy tecnica o valores de infraestructura si son estaticos
- tema y tokens base de la app

## Que no va aqui

- env vars
- tokens visuales heredados del tema actual

## Checklist para contributors

- Si la constante pertenece a una sola feature, evalua dejarla dentro de esa feature.
