# src/config

Configuracion de runtime y resolucion de entorno.

## Que va aqui

- lectura y validacion de config de app
- resolucion de base URLs
- flags de entorno y capacidades habilitadas

## Que no va aqui

- constantes de UI
- secretos hardcodeados

## Checklist para contributors

- Si una configuracion cambia por ambiente, probablemente va aqui.
- Valida temprano y falla de forma clara.
