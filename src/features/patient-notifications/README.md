# src/features/patient-notifications

Feature para listar y marcar notificaciones del paciente.

## Que va aqui

- queries de notificaciones
- componentes de listado y estados vacios
- acciones de marcado como leido o leido total

## Checklist para contributors

- Mantiene esta feature alineada con los endpoints de notificaciones del paciente.
- Si aparece UI reutilizable, extraela a capas compartidas.
