# src/features/patient-home

Feature de entrada para el paciente autenticado o anonimo.

## Que va aqui

- pantalla principal del paciente
- resumen de estado de sesion
- accesos a proximos flujos del producto

## Checklist para contributors

- Mantiene esta feature como entrypoint del paciente.
- Si aparecen widgets reutilizables, extraelos a `src/components` o `src/ui`.
