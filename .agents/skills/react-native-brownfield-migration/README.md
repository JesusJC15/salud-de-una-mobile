# docs/agent-skills/react-native-brownfield-migration

Skill para integraciones brownfield y convivencia con aplicaciones nativas existentes.

## Que vas a encontrar aqui

- `SKILL.md` con el flujo base
- `agents/` para soporte asociado
- `references/` con instrucciones por plataforma

## Cuando usar esta skill

- si el proyecto necesitara integrarse a una app nativa existente
- si se evalua pasar de Expo administrado a escenarios mas hibridos

## Checklist para contributors

- Usa esta skill solo cuando el caso realmente sea brownfield.
- No mezcles sus decisiones con el flujo normal del repo sin necesidad.
